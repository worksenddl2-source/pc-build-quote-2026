**웹 페이지:** https://worksenddl2-source.github.io/pc-build-quote-2026/

> 가격은 2026-10-28 다나와 상품 페이지에 표시된 값입니다. 실시간으로 바뀌며, 회원 쿠폰·적립은 반영하지 않았습니다.
